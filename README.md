# ESTUDO-DE-ESTRUTURA-DE-DADOS-EM-C
Este repositório contém soluções de exercícios em linguagem C

## Estrutura
- Arquivos `.c` com os códigos-fonte
- Pasta `output/` ignorada no Git, destinada aos executáveis gerados

## Como compilar (Windows/PowerShell)
Exemplo com GCC (MinGW):

```powershell
# Compilar um arquivo
gcc Exerc1.c -o output/Exerc1.exe

# Executar
./output/Exerc1.exe
```

Ajuste o nome do arquivo conforme necessário.
