# ESTUDO DE ESTRUTURA DE DADOS EM C

## Sobre o Repositório

Usarei de repositório para as minhas resoluções do beecrowd da matéria de Estrutura de Dados na linguagem C.

Este repositório contém implementações e soluções de problemas relacionados ao estudo de estruturas de dados, desenvolvidas como parte da disciplina de Estrutura de Dados. Todas as soluções são implementadas na linguagem de programação C.

## Objetivos

- 📚 Estudar e implementar diferentes estruturas de dados
- 💻 Resolver problemas do BeeCrowd relacionados à estrutura de dados
- 🔧 Praticar programação em linguagem C
- 📊 Documentar o processo de aprendizagem

## Estruturas de Dados Abordadas

- Listas
- Pilhas (Stacks)
- Filas (Queues)
- Árvores (Trees)
- Grafos (Graphs)
- Tabelas Hash
- E outras estruturas fundamentais

## Como Usar

1. Clone o repositório
2. Navegue até a pasta da estrutura de dados desejada
3. Compile os arquivos C usando um compilador como GCC
4. Execute os programas para testar as implementações

## Compilação

```bash
gcc -o programa programa.c
./programa
```
